# 动效模块（motions）设计方案

## 1. 动效与排版的边界及三种互动模式

### 核心边界
- **动效层（Motion）负责**：视觉母题（准星/枝叶/印章/蓝图/声呐）、SVG 装饰图形、SMIL 动画轨迹、`animated` 静态/动态双态切换。
- **禁止越界**：不硬编码任何业务文案（如 `FULL ARTICLE`、动效皮肤名称）、不自行编排作者/日期/标签、不覆盖排版层的外层卡片样式。

### 三种标准互动模式
1. **包裹型（Frame）** — 用于 **Banner 大标题**、**空白图占位**、**Tail 底部收束**
   - 动效提供外框与对称画框；排版层不再叠加同质边框或重复顶栏，仅向动效传入纯语义内容（如 `{ eyebrow, titleHtml }` 或 `{ label }`）。
2. **伴随型（Companion）** — 用于 **TOC 右上角**、**H2 右侧**、**H3 左侧**、**引用块**、**代码块**、**作者名片**
   - 排版层在固定锚点预留标准尺寸槽位，动效 SVG 严格贴合尺寸，不撑破原有行高与边距。
3. **独立型（Standalone）** — 用于 **H2 下方轨道（Section Rail）**、**分割线（Divider）**
   - 排版层仅控制上下 `margin`，动效输出 `width: 100%` 自适应 SVG。

## 2. 槽位体系契约（MotionPreset）

### 核心主槽位
1. **大标题包裹框（`renderBannerFrame`）**
   - 入参：`{ eyebrow, titleHtml }`、`colors`、`animated`（`eyebrow` 由排版层传入文章分类，不再显示动效名）。
   - 结构：顶部双色块与左右延展线 + 四角 L 形边角 + 右侧主题徽章与点阵 + 底部对称动效簇与流动脊线；适当增加上下留白以保持呼吸感。
   - 兼容：保留 `renderBannerMotion` 作为纯底部动效条供轻量场景复用。

2. **引言 / 导览右上角装饰（`renderTocDecor`）**
   - 用途：固定放置于 TOC 导览、引言卡片**右上角**（与标题行对齐）。
   - 尺寸规范：全预设统一采用扁平比例 **`viewBox="0 0 84 32"`**，避免过高的垂直占用挤压下方卡片或正文内容。

3. **二级标题组合装饰（`renderSectionBadge` + `renderSectionRail`）**
   - `renderSectionBadge(colors, animated, index)`：置于 H2 标题右侧。**延长线禁止设置 `min-width`**，窄空间或长标题折行时自动压缩/隐藏，仅保留右侧紧凑徽章（固定 `44~52px`），严禁将徽章挤出容器。延长线上的装饰节点（圆点、菱形等）须置于水平正中心并严格贴合线条轨迹。
   - `renderSectionRail(colors, animated, index)`：置于 H2 标题下方，贯穿左右的流动轨道线与节点。**SVG `viewBox` 顶部留白须紧凑且不裁切运动主体**（如滚动齿轮须按外径预留顶部空间，确保齿廓完整显示）。

4. **空白 / 无效图片占位装饰（`renderImagePlaceholder`）**
   - 用途：当图片地址为空、为占位关键字（`placeholder`、`待补充`、`example.com`、相对文件名等）或实际加载失败（`error` 回退）时，渲染居中主题插画 + `VISUAL SLOT / 16:9` + 提示文案。

5. **底部收束装饰（`renderTail`）**
   - 用途：文章末尾 `END · 继续阅读` 对称收束模块。
   - 结构：左中右平级布局（左侧动效图形 — 居中收尾文案 — 右侧动效图形）+ 底部贯穿流动脊线。

---

### 扩展轻装饰槽位（与排版联动）
6. **三级标题微标记（`renderH3Marker`）**：`14×14` 轻量动效图标。当排版层开启**无编号模式（`headingNumbering === 'none'`）**时展示在 H3 左侧；开启**自动编号模式（`numeric`）**时由 `2.1` 小序号替代，避免双重前缀。**H4 不介入动效**，保持主次层级。
7. **引用块角标（`renderBlockquoteDecor`）**：置于 `blockquote` 左上/右上角，全预设统一采用 **`viewBox="0 0 36 24"`**（`width="36"`），保持引用块顶部高度一致，且图形需贴合本套动效主题，禁止出现无关联的刻度或多余装饰。
8. **文末作者名片微装饰（`renderEndingDecor`）**：置于 `renderEnding` 卡片右上角，与 `renderTail` 形成过渡呼应。
9. **代码块状态点（`renderCodeBadge`）**：置于代码块 Mac 顶栏右侧，呈现微弱状态指示灯。

## 3. 单一动效的视觉统一性规范

为避免同一套动效在不同区域出现“线宽忽粗忽细、缩放发虚、图案风格割裂”的问题，所有动效实现必须遵守以下三条铁律：

### 3.1 渲染线宽统一（按最终屏幕像素校准）
- **Banner 主标题区（最高视觉层级）**：外框主线与主徽章线宽 **1.5px ~ 2.0px**，强调轨迹 **2.0px**，辅助刻度 **0.8px ~ 1.0px**。
- **全篇其余槽位（TOC / H2 徽章与轨道 / 占位图 / Tail / H3 / 引用 / 代码 / 名片）保持统一基准**：
  - 主轮廓线：**1.2px ~ 1.4px**
  - 辅助细线 / 刻度：**0.8px ~ 0.9px**（实际渲染线宽严禁低于 `0.7px`）
  - 流动光轨（`flowTrailSvg`）：**1.6px ~ 1.8px**
- **防缩放失真与防拥挤约束**：小尺寸槽位（`renderTocDecor`、`renderSectionBadge`、`renderBlockquoteDecor` 等）的 SVG `viewBox` 必须与实际渲染尺寸同量级（例如 `72px` 宽的 TOC 容器统一使用扁平 `viewBox="0 0 84 32"`，引用块统一 `viewBox="0 0 36 24"`），严禁硬塞过多动态元素或大跨度位移动画导致线条重叠粘连，元素间应留出清晰呼吸间隙。

### 3.2 单套动效「母题唯一性 + 三级细节（LoD）」
每套动效只允许定义 **1 个核心主图元（Primary Motif）** 和 **1 个辅助特征（Secondary Accent）**，通过共享 SVG Builder 在全篇复用，仅按槽位大小裁剪细节，禁止在不同槽位另起炉灶画不同图案或借用跨主题元素（如非测量类主题禁用刻度尺，植物类图元须保持完整的叶与杆结构）：
- **Lv.1 完整版（Banner / 占位图 / Tail）**：主图元 + 辅助特征 + 流动脊线或轨道。
- **Lv.2 精简版（TOC 右上角 / H2 右侧徽章）**：主图元 + 核心辅助特征（去除过密细线与易重叠滑块，保证 `48~74px` 尺寸下锐利清晰）。
- **Lv.3 微缩版（H3 / 引用 / 代码 / 名片）**：仅保留主图元的**最小几何轮廓**（不超过 5 个基础图元），线宽与 Lv.2 一致。

| 动效预设                   | 唯一主图元（Primary Motif）   | 辅助特征（Secondary Accent） |
| :------------------------- | :---------------------------- | :--------------------------- |
| `meridian-grid` 经纬线网   | 正交十字准星 + 方形坐标框     | 等距基准网格线 + 坐标节点    |
| `lotus-leap` 荷下鱼跃      | 摆尾游鱼 + 摇曳荷叶（带荷杆） | 盛开荷花 + 多层流动水波      |
| `precision-gear` 精工齿轮  | 咬合齿廓圆环 + 中心轴销       | 固定导轨实线 + 物理同步滚动  |
| `glow-terminal` 微光终端   | 终端提示符 `>_` + 呼吸光标    | 水平虚线基轨 + 顺序扫描光标  |
| `acoustic-wave` 清弦声纹   | 对称律动音柱簇 + 音频播放律动 | 正弦谐波曲线 + 中心圆点      |
| `celestial-orbit` 星轨天象 | 双倾角椭圆星轨 + 中心恒星     | 伴星公转节点 + 弧形天轨      |

## 4. 配色、密度与工程边界规范
- **调色盘联动与主色分层**：所有动效严格通过 `resolveMotionColors(colors)` 消费 `PaletteColors`，装饰外框与辅助线条均使用主色调 `headingDecor` 及其透明分层（`primaryMid` / `primarySoft`）与强调色 `strong`，禁止在浅色主题下使用突兀的纯黑线。
- **中心母题与槽位分工铁律**：
  - **Banner 右上角徽章**：必须放置该动效的**唯一中心主图元**（如星轨用双椭圆星轨、鱼跃用优雅游鱼、齿轮用主齿轮）。
  - **H2 延长线与底轨差异化**：各预设的 H2 延长线与 `renderSectionRail` 需在形态（直线/双反向流线/虚线/波浪/锯齿/无底轨留白）上明确区分。
  - **Banner 底部与 Tail 非对称收束**：左右图形采用同主题非对称呼应（如星轨左日右月），Tail 右侧禁止出现跨主题雷同图形（如通用柱状图）。
  - **运动物理真实性与视觉舒适度**：
    - **朝向与路径一致**：往返游动的主体（如游鱼）须在折返点通过离散翻转（`scale(1 1)` / `scale(-1 1)` + `calcMode="discrete"`）保持头部朝向运动方向，严禁倒退游动；具象生物可叠加局部高频微动（如鱼尾摆动）提升生动感。
    - **滚动角速度与线速度同步**：沿轨道往返滚动的齿轮须按外径 $R$ 与单程位移 $\Delta x$ 匹配旋转角度（$\theta = \frac{\Delta x}{R} \cdot \frac{180}{\pi}$），并随去程/返程同步正反转，消除“打滑”感；滚动轨道保持静态实线，避免移动线段分散视线。
    - **柔和渐进、禁止高频刺眼闪烁**：多节点阵列动效（如终端光标扫描、声波律动柱）应通过等距 `begin` 延迟形成从左到右的连续播放/扫描感；动画周期宜舒缓（`7~11s`），透明度过渡需加入淡入淡出关键帧并克制峰值对比度，避免密集频闪导致视觉疲劳。
  - **轨道粒子贴合路径**：沿椭圆或曲线轨道运行的粒子必须使用 `<animateMotion>` 贴合路径运动，严禁使用圆周 `rotate` 替代椭圆轨道导致脱轨。
- **视觉密度阶梯**：Banner / Tail（重度收束） → TOC / H2 / 占位图（中度节奏） → H3 / 引用 / 代码 / 名片（极轻点缀） → H4（无动效）。
- **静态首帧完整性（微信兼容）**：`animated === false` 时必须输出纯静态 SVG（不包含 `<animate>` / `<animateTransform>`）；且动态 SVG 的首帧静态构图必须完整美观，兼容不支持 SMIL 动画的微信客户端版本。
- **自适应防裁切**：Banner 包裹框左右侧栏需随大标题折行高度自适应拉伸；所有 SVG 根元素统一设置 `display:block;width:100%;height:auto;max-width:100%;`。`viewBox` 边界须覆盖完整图形外径与动画幅度，防止边缘被裁切。
