# 动效模块（motions）设计方案

## 1. 动效与排版的边界及三种互动模式

### 核心边界
- **动效层（Motion）负责**：视觉母题（准星/枝叶/印章/蓝图/声呐）、SVG 装饰图形、SMIL 动画轨迹、`animated` 静态/动态双态切换。
- **禁止越界**：不硬编码任何业务文案（如 `FULL ARTICLE`、动效皮肤名称）、不自行编排作者/日期/标签、不覆盖排版层的外层卡片样式。

### 三种标准互动模式
1. **包裹型（Frame）** — 用于 **Banner 大标题**、**空白图占位**、**Tail 底部收束**
   - 动效提供外框与对称画框；排版层不再叠加同质边框或重复顶栏，仅向动效传入纯语义内容（如 `{ eyebrow, titleHtml }` 或 `{ label }`）。
2. **伴随型（Companion）** — 用于 **TOC 右上角**、**H2 右侧**、**H3 左侧**、**引用块**、**代码块**、**作者名片**
   - 排版层在固定锚点预留标准尺寸槽位，动效 SVG 严格贴合尺寸，不撑破原有行高与边距。
3. **独立型（Standalone）** — 用于 **H2 下方轨道（Section Rail）**、**分割线（Divider）**
   - 排版层仅控制上下 `margin`，动效输出 `width: 100%` 自适应 SVG。

## 2. 槽位体系契约（MotionPreset）

### 核心主槽位
1. **大标题包裹框（`renderBannerFrame`）**
   - 入参：`{ eyebrow, titleHtml }`、`colors`、`animated`（`eyebrow` 由排版层传入文章分类，不再显示动效名）。
   - 结构：顶部双色块与左右延展线 + 四角 L 形边角 + 右侧主题徽章与点阵 + 底部对称动效簇与流动脊线；适当增加上下留白以保持呼吸感。
   - 兼容：保留 `renderBannerMotion` 作为纯底部动效条供轻量场景复用。

2. **引言 / 导览右上角装饰（`renderTocDecor`）**
   - 用途：固定放置于 TOC 导览、引言卡片**右上角**（与标题行对齐）。

3. **二级标题组合装饰（`renderSectionBadge` + `renderSectionRail`）**
   - `renderSectionBadge(colors, animated, index)`：置于 H2 标题右侧。**延长线禁止设置 `min-width`**，窄空间或长标题折行时自动压缩/隐藏，仅保留右侧紧凑徽章（固定 `44~52px`），严禁将徽章挤出容器。
   - `renderSectionRail(colors, animated, index)`：置于 H2 标题下方，贯穿左右的流动轨道线与节点圆点。**SVG `viewBox` 顶部留白须紧凑（主轨道贴近顶部 `y=4~8`）**，确保线条紧贴标题底部，不产生过大空白间距。

4. **空白 / 无效图片占位装饰（`renderImagePlaceholder`）**
   - 用途：当图片地址为空、为占位关键字（`placeholder`、`待补充`、`example.com`、相对文件名等）或实际加载失败（`error` 回退）时，渲染居中主题插画 + `VISUAL SLOT / 16:9` + 提示文案。

5. **底部收束装饰（`renderTail`）**
   - 用途：文章末尾 `END · 继续阅读` 对称收束模块。
   - 结构：左中右平级布局（左侧动效图形 — 居中收尾文案 — 右侧动效图形）+ 底部贯穿流动脊线。

---

### 扩展轻装饰槽位（与排版联动）
6. **三级标题微标记（`renderH3Marker`）**：`14×14` 轻量动效图标。当排版层开启**无编号模式（`headingNumbering === 'none'`）**时展示在 H3 左侧；开启**自动编号模式（`numeric`）**时由 `2.1` 小序号替代，避免双重前缀。**H4 不介入动效**，保持主次层级。
7. **引用块角标（`renderBlockquoteDecor`）**：置于 `blockquote` 右上角，提供轻量脉冲/角标。
8. **文末作者名片微装饰（`renderEndingDecor`）**：置于 `renderEnding` 卡片右上角，与 `renderTail` 形成过渡呼应。
9. **代码块状态点（`renderCodeBadge`）**：置于代码块 Mac 顶栏右侧，呈现微弱状态指示灯。

## 3. 单一动效的视觉统一性规范

为避免同一套动效在不同区域出现“线宽忽粗忽细、缩放发虚、图案风格割裂”的问题，所有动效实现必须遵守以下三条铁律：

### 3.1 渲染线宽统一（按最终屏幕像素校准）
- **Banner 主标题区（最高视觉层级）**：外框主线与主徽章线宽 **1.5px ~ 2.0px**，强调轨迹 **2.0px**，辅助刻度 **0.8px ~ 1.0px**。
- **全篇其余槽位（TOC / H2 徽章与轨道 / 占位图 / Tail / H3 / 引用 / 代码 / 名片）保持统一基准**：
  - 主轮廓线：**1.2px ~ 1.4px**
  - 辅助细线 / 刻度：**0.8px ~ 0.9px**（实际渲染线宽严禁低于 `0.7px`）
  - 流动光轨（`flowTrailSvg`）：**1.6px ~ 1.8px**
- **防缩放失真约束**：小尺寸槽位（`renderTocDecor`、`renderSectionBadge`、`renderBlockquoteDecor` 等）的 SVG `viewBox` 必须与实际渲染尺寸同量级（例如 `72px` 宽的容器使用 `viewBox="0 0 84 60"`，禁止用 `280×180` 硬缩小 4 倍），或使用 `vector-effect="non-scaling-stroke"`，确保全篇线条视觉粗细完全一致。

### 3.2 单套动效「母题唯一性 + 三级细节（LoD）」
每套动效只允许定义 **1 个核心主图元（Primary Motif）** 和 **1 个辅助特征（Secondary Accent）**，通过共享 SVG Builder 在全篇复用，仅按槽位大小裁剪细节，禁止在不同槽位另起炉灶画不同图案：
- **Lv.1 完整版（Banner / 占位图 / Tail）**：主图元 + 辅助特征 + 刻度与流动脊线。
- **Lv.2 精简版（TOC 右上角 / H2 右侧徽章）**：主图元 + 核心辅助特征（去除过密细线，保证 `48~74px` 尺寸下锐利清晰）。
- **Lv.3 微缩版（H3 / 引用 / 代码 / 名片）**：仅保留主图元的**最小几何轮廓**（不超过 5 个基础图元），线宽与 Lv.2 一致。

| 动效预设                   | 唯一主图元（Primary Motif） | 辅助特征（Secondary Accent） |
| :------------------------- | :-------------------------- | :--------------------------- |
| `meridian-grid` 经纬线网   | 正交十字准星 + 坐标交叉点   | 等距基准网格线 + 游标滑块    |
| `abyssal-leap` 沧溟鱼跃    | 弧线跃影游鱼                | 同心水波涟漪 + 上升气泡      |
| `precision-gear` 精工齿轮  | 咬合齿廓圆环 + 中心轴销     | 导轨基准线 + 双轮传动        |
| `glow-terminal` 微光终端   | 终端提示符 `>_` + 呼吸光标  | 数据总线折线 + 状态微光      |
| `acoustic-wave` 清弦声纹   | 对称律动音柱簇              | 正弦谐波曲线 + 水平基线      |

## 4. 配色、密度与工程边界规范
- **调色盘联动与最低对比度**：所有动效严格通过 `resolveMotionColors(colors)` 消费 `PaletteColors` 的 5 个语义色（`headingDecor` 主轨、`strong` 强调点、`divider` 辅助刻度、`heading` 深色墨线、`bg` 挖空底色），不硬编码色值。浅色调色盘下底轨透明度不低于 `0.45`，避免轨道线在白底上“消失”。
- **视觉密度阶梯**：Banner / Tail（重度收束） → TOC / H2 / 占位图（中度节奏） → H3 / 引用 / 代码 / 名片（极轻点缀） → H4（无动效）。
- **静态首帧完整性（微信兼容）**：`animated === false` 时必须输出纯静态 SVG（不包含 `<animate>` / `<animateTransform>`）；且动态 SVG 的首帧静态构图必须完整美观，兼容不支持 SMIL 动画的微信客户端版本。
- **自适应防裁切**：Banner 包裹框左右侧栏需随大标题折行高度自适应拉伸；所有 SVG 根元素统一设置 `display:block;width:100%;height:auto;max-width:100%;`。
