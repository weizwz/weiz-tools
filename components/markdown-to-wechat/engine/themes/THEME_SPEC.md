# 排版模块（themes）设计方案

## 1. 职责边界：排版 × 动效正交解耦
- **排版层（Theme）负责**：空间骨架、卡片外壳（圆角/阴影/底色）、字号/字重/行高、业务元信息编排（分类/作者/头像/日期/标签）、调色盘语义映射及动效插槽挂载。
- **禁止越界**：排版层不手写复杂装饰 SVG；当某区域采用「动效包裹框（Frame）」时，排版层不得再叠一层同质边框或重复的顶部信息栏，消除“框套框”。

---

## 2. 章节编号开关（`headingNumbering`）

### 2.1 配置与计数规则
- 在 `RenderOptions` 与工具栏新增全局开关：`headingNumbering: 'numeric' | 'none'`（**自动编号** / **无编号**）。
- 渲染器（`renderer.ts`）维护 `h2Index` 与 `h3Index`：每遇到一个 H2，`h2Index++` 且重置 `h3Index = 0`；每遇到一个 H3，`h3Index++`。无需在 Markdown 原文手写序号。

### 2.2 全篇联动规范
| 区域 | **自动编号（`numeric`）** | **无编号 / 并列模式（`none`）** |
| :--- | :--- | :--- |
| **TOC 导览** | 显示 `PART 01` / `01` 序号 | 隐藏数字，改为小圆点或短横指示符 |
| **H2 二级标题** | 显示大序号块（如 `01` / `PART`） | 隐藏数字，替换为**主题色短竖条 / 几何块** |
| **H3 三级标题** | 显示等幅小序号 **`2.1`**（归属当前 H2）+ 标题 | 显示 **`renderH3Marker` 动效微图标** + 标题 |
| **H4 四级标题** | 无编号，纯局部小标 | 无编号，纯局部小标 |

## 3. 四级标题视觉层级（拆分 `renderH3` 与 `renderH4`）
在 `renderer.ts`（`depth >= 4`）和 `LayoutTheme.slots` 中新增独立的 `renderH4` 槽位，拉大层级区分度：

| 层级 | 字号与字重（基于 `baseFont`） | 留白节奏（上/下） | 动效介入 | 视觉表现 |
| :--- | :--- | :--- | :--- | :--- |
| **H1（Banner）** | `baseFont + 5px` / `800-900` | 独立头图区 | **重度**（`renderBannerFrame`） | 动效画框包裹「文章分类 + 主标题」 |
| **H2** | `baseFont + 2~3px` / `800-900` | `28px / 14px` | **中度**（`renderSectionBadge` + `renderSectionRail`） | 大序号/竖条 + 可折行标题 + 右侧固定徽章 + 紧贴底部的轨道 |
| **H3** | `baseFont + 1px` / `700` | `22px / 10px` | **轻度**（无编号时显示 `renderH3Marker`） | `2.1` 小序号或微图标 + 加粗标题，无底线轨道 |
| **H4** | `baseFont` / `700` | `16px / 6px` | **无动效** | 2px 浅色短竖线或极浅底色胶囊标签（如 `图解`），轻量紧凑 |

## 4. 大标题区（Banner）与元信息收口方案
- **去掉重复顶栏**：移除当前画框上方多余的 `● 分类 —— 日期` 横栏，避免三层嵌套。
- **画框内纯粹化**：向动效 `renderBannerFrame` 仅传入 `{ eyebrow: 文章分类, titleHtml: 主标题 }`（未填分类时兜底 `FULL ARTICLE`），去掉无意义的动效名称展示。
- **元信息收口至底栏**：日期统一移入主题底部元信息栏，与作者合并展示为 `作者 · YYYY-MM`：
  - **知微卡片（`knowledge-card`）**：圆角微投影知识卡 + 动效画框 + 主题色通栏底栏（左 `头像 + 作者 · 日期` / 右 `标签`）。
  - **札书手记（`book-notes`）**：暖米白纸感手记卡 + 动效画框 + 深胡桃木通栏底栏（左 `头像 + 作者 · 日期` / 右 `标签`）。
  - **星澜简报（`tech-brief`）**：极简细框通讯卡 + 动效画框 + 留白底栏（左 `头像 + 作者 · 日期` / 右 `标签`）。
  - **即刻短笺（`social-feed`）**：大圆角社交卡 + 动效画框 + 轻胶囊底栏（左 `头像 + 作者 · 日期` / 右 `标签`）。
  - **画报期刊（`editorial-journal`）**：柔和白卡画报 + 动效画框 + 留白底栏（左 `标签` / 右 `头像 + 作者 · 日期`）。
  - **行旅明信（`travel-postcard`）**：暖沙明信片卡 + 动效画框 + 松柏绿通栏底栏（左 `头像 + 作者 · 日期` / 右 `邮票标签`）。
  - **极客终端（`hacker-terminal`）**：深墨框终端卡 + 动效画框 + 命令行底栏（左 `$ 作者 · 日期` / 右 `等宽标签`）。
  - **山水清音（`ink-landscape`）**：宣纸素白卡 + 动效画框 + 素净留白底栏（左 `标签` / 右 `头像 + 作者 · 日期`）。

## 5. 其他常规排版槽位约定
- **TOC 导览**：标题行右侧固定预留右上角挂载槽，放置 `renderTocDecor`。
- **图片与占位**：有效图片渲染卡片外框 + `<figcaption>`；空地址、占位关键字或加载失败图片由动效 `renderImagePlaceholder` 接管。
- **引用块**：采用紧凑间距（`margin:14px 0;padding:12px 16px`），将 `renderBlockquoteDecor`（`width:28px`）置于左上角首行左对齐，正文在下方另起一行占满全宽，并清理引用内末尾 `<p>` 的底部多余 `margin`。
- **代码块 / 作者名片**：在顶栏右侧或卡片右侧预留固定尺寸锚点，挂载轻量动效角标，不改变正文行高与内边距。

## 6. 边界场景与防错规范（必检项）

1. **长标题折行防溢出与动效防裁切（H2 / H1）**
   - **直接挂载 `renderSectionBadge`，严禁外层套窄容器**：`motion.renderSectionBadge` 内部已包含 `flex:1;min-width:48px` 容器（左侧 `flex:1;min-width:0` 延伸线 SVG + 右侧 `width:48px;flex-shrink:0` 徽章），排版层不得在其外层再套固定宽度（如 `46px`）容器，避免裁切右侧徽章或把延伸线压成 `0px` 空白 SVG。
   - **H2 标题容器不设 `flex:1` 与 `flex-shrink:0`**：标题文本容器仅设 `min-width: 0; word-break: break-word;`，短标题时只占自身内容宽以留出延伸线空间，长标题时允许自然折行且保证右侧 `48px` 动效徽章完整显示、绝不挤出容器右边界。
   - **H2 下方轨道紧贴标题**：`rail` 容器不加多余 `margin-top`（控制在 `0~2px`），与数字块/标题底边保持紧凑视觉关联。
   - **375px 窄屏安全**：Banner 左右动效侧栏总宽控制在 `<= 56px`，所有外层容器加 `max-width: 100%; overflow: hidden; box-sizing: border-box;`，杜绝横向滚动条。
2. **微信编辑器粘贴兼容**
   - 全程使用 **Inline CSS + Flexbox + 原生 SVG**，禁止依赖 `position: absolute` 叠层或 CSS Grid，防止微信公众号后台过滤或错位。
3. **缺省内容兜底**
   - 无 H1 不渲染 Banner；H2 少于 2 个不渲染 TOC；超过 6 个 H2 时 TOC 截断展示（避免卡片过长）。
   - 分类为空时，Banner 顶部 `eyebrow` 隐藏或兜底 `ARTICLE`；图片 `alt` 为空时，占位卡自动显示 `${motion.name} · 图片待补充`。
